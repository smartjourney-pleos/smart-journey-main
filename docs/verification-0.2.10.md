# 0.2.10 검증 기록 (2026-11-13)

소스: [smart-journey-android @ `d84e740`](https://github.com/smartjourney-pleos/smart-journey-android/tree/d84e740ce14b6ba579ed0c7028e45386daeefe33)(main). 자세한 앱 기록은 소스의 `docs/verification/release-0.2.10.md`, `release-0.2.9.md`에 있다.

## 바뀐 점

- **Gleo를 통한 접수·인원 변경 승인을 막고 상태 조회만 남겼다.**
  - Gleo Action은 모델이 만든 파라미터(`ACTION_PARAM`)만 앱에 전달한다. 그래서 사용자가 새로 답했다는 증거가 없다(공개 Gleo Interface 가이드, 설치된 Gleo AI 4.2.0.15 확인).
  - 스키마에는 `GET_SMART_JOURNEY_STATUS`만 있다. 예전 응답 함수로 호출이 와도 아무것도 실행하지 않는다.
- 승인은 앱이 질문을 다 읽은 뒤 앱 STT로 받은 답과 정차 중 터치로만 받는다.
- 0.2.9: 방문 시작 직후 순정 내비에서 "안내 종료"를 누르면 접수 전 방문이 남던 문제를 고쳤다(내비 경로 상태 확인).

## 미확인·제약

- 사람이 말하는 마이크 입력과 Gleo 대화 전체 흐름은 검증하지 못했다.
- 일반 설치에서는 지도 위 카드가 뜨지 않는다. 현재 Pleos 에뮬레이터 이미지에서는 "다른 앱 위 표시" 권한을 허용하는 설정 화면을 찾지 못했다. 이 에뮬레이터에서 관찰한 제약이며, 공식 금지로 확인한 것은 아니다.
- 순정 내비의 안내 종료 전에 확인을 받을 수 없다(공개 이벤트 없음). 앱의 "방문 끝내기"만 확인창을 거친다.
- 접수는 앱 안의 시연 데이터(`FakeBackend`)이며 실제 매장에 접수되지 않는다. 좌석 인원과 하차는 제안·추정이다.
